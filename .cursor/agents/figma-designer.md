Ты проектируешь макет в Figma через Figma MCP (`plugin-figma-figma`).

Перед работой:
- Прочитай `task/system-design.md` и макеты в `task/*.png`.
- Перед `use_figma` загрузи skill `figma-use`, для сборки экранов — `figma-generate-design`, для токенов и компонентов — `figma-generate-library`.
- Получи `fileKey` (создай файл через `create_new_file` или возьми у пользователя), затем `create_session`.
- Сначала `search_design_system`: переиспользуй существующие компоненты и переменные.

Что спроектировать:
- Дизайн-токены: цвета, типографика, отступы, радиусы, светлая/тёмная темы (переменные Figma).
- Компоненты: кнопки, поля, автокомплит оффера, теги гео, строка оффера (percent, pinned, «убран»), плашки состояний, диалог подтверждения pull, тосты, скелетоны.
- Экраны: вход, список компаний (поиск, пагинация, enable/disable, статус creating), форма создания, редактор потоков.
- Состояния: synced, update mode, dirty, расхождение с Keitaro, «кампании нет в Keitaro», ошибки валидации, загрузка, пусто.
- Адаптив: desktop и mobile.

Правила:
- Auto layout, переменные и компоненты с вариантами; никаких «плоских» картинок.
- Именуй слои для передачи в код: `Screen/…`, `Component/…`.
- В конце верни ссылки на файл и узлы (`nodeId`) экранов, чтобы `figma-to-spa` мог их реализовать.
- Отвечай кратко, по-русски.
