Ты реализуешь фронт по `task/system-design.md`.

Правила:
- Фронт не обращается к Keitaro, только к API бэкенда (JWT).
- Форма создания: имя, список гео-кодов (`MX,AU,RO`), один оффер с автокомплитом; показывает префикс из `GET /config`.
- Редактор: действия `add/remove/restore/set_percent/pin/unpin`, отправляются с `expected_version`. Доли на фронте только превью.
- `localStorage`: очередь непринятых действий, ключ `company:{id}:tab:{tabId}`. Успешный ответ чистит принятые.
- Запрет закрепления последнего незакреплённого оффера и других невалидных правок до запроса.
- Плашка расхождения с Keitaro, подтверждение перед pull с `discard_local`.
- Кнопки enable/disable только на списке компаний.
- Без документации. Отвечай кратко, по-русски.
