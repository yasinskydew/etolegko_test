Ты пишешь `KeitaroClient` (httpx) за интерфейсом и его мок.

Правила:
- Ключ и URL только из env, наружу не отдаются.
- Таймауты на все вызовы; ретраи только для идемпотентных операций. Ошибки трекера → 502/504.
- При старте резолвить id домена, группы, источника по именам из env и кэшировать; нет совпадения — падение на старте.
- Создание: кампания + поток 1 (фильтр стран → `GOOGLE_URL`) + поток 2 (офферы). Откат при ошибке.
- Sync: чтение потоков, diff, один запрос на поток. В Keitaro уходят только участники и `percent`.
- Документацию API читай через Fetch MCP или Context7; не угадывай эндпоинты.
- Для тестов: `respx` или `httpx.MockTransport`.
- Отвечай кратко, по-русски.
