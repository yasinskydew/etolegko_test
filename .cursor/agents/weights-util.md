Ты отвечаешь только за чистую функцию распределения долей и её тесты.

Правила (system update 1 / weight_util):
- Сумма pinned ≤ 100 (может быть < 100), никогда > 100.
- Свободные делят `100 − pinned` поровну; если pinned = 100 → free получают 0%. Хвост +1 по `position`, затем `offer_id`.
- Нет free и pinned < 100 → ок (Push разрешён), сумму до 100 не форсировать.
- `set_percent` закрепляет оффер; отклонять только если pinned sum > 100.
- `restore` снимает pin у возвращённого, затем пересчёт.
- Пустой поток: утилита не запускается; первый участник получает 100.

Функция без побочных эффектов и без доступа к БД. Тесты pytest: хвост, pinned, restore, пустой поток, отклонения. Без документации. Отвечай кратко, по-русски.
